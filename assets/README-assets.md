# Screenshot assets

Put your PNGs in this folder using these exact filenames. The main `README.md` and the article both reference them by name.

| Filename | What it shows |
| :--- | :--- |
| `capability-profile.png` | Notion Capability Profile database, all 17 rows visible |
| `contract-pipeline.png` | Notion Contract Pipeline populated with scored contracts |
| `console-input.png` | Apify Console input tab, both connector pickers visible |
| `run-log-scoring.png` | Log block: profile contribution, ranking changed, biggest effect |
| `run-log-dedupe.png` | Log block: duplicate suppression on the second run |

Keep each under 1 MB, around 1600px wide. Crop out browser chrome and your bookmarks bar.

Once pushed to GitHub, the public URL for each is:

```
https://raw.githubusercontent.com/IshekKhal/REPO-NAME/main/assets/FILENAME.png
```
